[PRD] MYP IB 성적 변환 및 성적표 발급 웹앱
문서 버전: v1.0

작성일: 2026년 9월 16일

대상 사용자: 중학교 IB MYP 교과 담당 교사 및 관리자

1. 제품 개요 (Product Overview)
대한민국 국가교육과정 기반의 평가 데이터를 활용하여 IB MYP(Middle Years Programme) 평가 기준(Criterion A, B, C, D)에 부합하는 점수로 변환하고, 최종 IB 등급 산출 및 서면 성적표 출력을 지원하는 웹앱입니다.

핵심 목표: IB 평가 체계에 대한 깊은 지식이 없는 교사도 쉽게 점수를 변환하고 규정에 맞는 서면 성적표를 출력할 수 있도록 지원.

주요 특징:

별도의 데이터 저장/아카이빙 없이 단기 세션 내 입력 및 서면 출력에 집중.

모든 교사가 동일한 관리자 권한을 공유하는 단일 권한 구조.

2. 사용자 및 권한 (User & Permissions)
사용자 그룹: 중학교 교사 전체

권한 모델: 공유 관리자 권한 (Shared Admin Role)

로그인/접근하는 모든 교사는 점수 입력, 기준 설정, 성적표 출력 등 시스템의 모든 기능을 제한 없이 이용할 수 있습니다.

3. 핵심 기능 요구사항 (Key Features)
3.1. IB MYP 점수 변환 및 산출 엔진
유닛 플랜(Unit Plan) 기반 평가 입력

한 학기 기준(예: 2개 유닛)의 평가 항목별 점수 입력 지원.

지필평가 점수 유무와 상관없이 MYP 4개 기준(Criterion A, B, C, D) 점수(각 1~8점) 직접 입력/변환 기능 제공.

최종 등급 산출 (1~7 Grade)

4개 기준 총점(최대 32점)을 기반으로 IB 공식 Boundary(점수 구간)에 맞춰 최종 1~7 등급 자동 산출.

지필평가가 미반영된 과목 및 유닛에 대해서도 평가 완료 시점에 맞춰 종합 산출 가능.

3.2. 서면 성적표 출력 (Print / Export)
출력 전용 성적표 생성

학생별 IB MYP 성적표 레이아웃 자동 생성.

포함 정보: 학생 기본 정보, 과목명, Criterion A/B/C/D별 점수, 종합 IB 등급(1~7), 일반 성취 기준 안내문.

PDF 내보내기 및 직접 인쇄

웹 브라우저 기반 즉시 인쇄(Print) 및 PDF 저장 기능 제공.

3.3. 데이터 처리 및 보안 (Data Handling)
비아카이빙(No-Archiving) 원칙

개인정보 보호 및 데이터 관리 단순화를 위해 서버에 학생 성적 기록을 영구 저장하지 않음.

세션 종료 또는 페이지 새로고침 시 입력 데이터 자동 초기화 (필요시 임시 파일 업로드/다운로드 기능 제공).

4. UI/UX 요구사항 (User Interface)
3단계 직관적 워크플로우:

과목/유닛 설정: 평가 기준 및 변환 루브릭 선택.

점수 입력: 학생별 Criterion A~D 점수 입력.

성적표 출력: 산출 결과 확인 후 일괄 인쇄/PDF 다운로드.

가이드 제공: IB 평가 용어가 낯선 교사를 위해 입력 화면 내 툴팁(Tooltip) 및 기준 설명 가이드 배치.

5. 향후 확장성 고려사항 (Non-Goals / Future Scope)
금회 제외 사항 (Non-Goals):

학기 간/학년 간 성적 이력 아카이빙 및 통계 분석 기능.

교사별/보호자별 차등 접근 권한(RBAC) 제어.

외부 교육청/NICE 시스템과의 자동 데이터 연동.
