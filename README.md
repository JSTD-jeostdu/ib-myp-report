# MYP 성적 변환 · 성적표 발급 웹앱

n**접속 주소:** https://jstd-jeostdu.github.io/ib-myp-report/
국가교육과정 평가 점수를 IB MYP 평가 기준(Criterion A~D, 0~8) 수준과 최종 등급(1~7)으로 바꾸고, 학생별 성적표를 인쇄하거나 PDF로 저장하는 웹앱입니다. 요구사항은 [PRD.txt](PRD.txt)에 있습니다.

## 구조

서버와 데이터베이스가 없는 정적 웹앱입니다. 학생 데이터는 브라우저 메모리에만 있고 외부로 보내지 않으며, 새로고침하면 사라집니다(PRD 3.3 비아카이빙 원칙). 작업을 이어서 하려면 **파일로 저장**(JSON)과 **불러오기**를 사용합니다.

```
index.html        화면 뼈대, 가이드 대화상자
css/style.css     화면 스타일 + A4 인쇄 스타일
js/myp-data.js    과목군별 Criterion, 수준 구간, 등급 경계·설명
js/app.js         상태 관리, 변환 계산, 3단계 화면, 파일 저장/불러오기
```

## 기능

1. **과목·유닛 설정**: 과목군(8개 + 기타), 유닛 추가/삭제, 유닛별 평가 기준과 입력 방식 선택
   - 직접 입력(0~8) / 원점수 → 백분율 환산 / 성취도 A~E → 수준
   - 변환표, 최종 수준 계산 방식(평균·최근·최고), 등급 경계(기본: MYP 1–5, 6–9, 10–14, 15–18, 19–23, 24–27, 28–32) 수정 가능
2. **점수 입력**: 엑셀 명단 붙여넣기, 유닛별 점수 표(엑셀 여러 칸 붙여넣기, Enter로 이동), 종합 탭에서 교사 조정(best-fit)과 교사 의견 입력
3. **성적표 출력**: 학생별 A4 성적표 미리보기, 출력 대상 선택, 인쇄/PDF 저장, 결과 CSV 내보내기

## 로컬에서 실행

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 을 엽니다.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다.

JS·CSS를 고친 뒤 배포할 때는 `index.html`의 `?v=1.0.0` 숫자를 올려야 교사들의 브라우저가 이전 파일을 캐시에서 쓰지 않습니다.

> 저장소가 공개(public)여도 코드만 공개되며, 학생 데이터는 저장소나 서버에 올라가지 않습니다. 저장한 JSON·CSV 파일에는 학생 이름과 성적이 들어 있으니 저장소 폴더에 넣지 마세요.
