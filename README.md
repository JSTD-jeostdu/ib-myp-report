# MYP 성적 변환 · 성적표 발급 웹앱

**접속 주소:** https://jstd-jeostdu.github.io/ib-myp-report/

나이스 성적 파일과 기준 템플릿(엑셀)으로 IB MYP 평가 기준(Criterion A~D, 0~8) 수준과 최종 등급(1~7)을 계산하고, 학생 1명당 전 과목 성적표를 인쇄하거나 PDF로 저장하는 웹앱입니다. IB 코디네이터·계원 교사용이며, 요구사항은 [PRD_v2_초안.md](PRD_v2_초안.md)에 있습니다. (v1 요구사항: [PRD.txt](PRD.txt))

## 구조

서버와 데이터베이스가 없는 정적 웹앱입니다. 엑셀 파일은 브라우저 안에서 [SheetJS](https://sheetjs.com/)로 읽고 외부로 보내지 않으며, 새로고침하면 사라집니다. 작업을 이어서 하려면 **파일로 저장**(JSON)과 **불러오기**를 사용합니다.

```
index.html        화면 뼈대, 가이드 대화상자
css/style.css     화면 스타일 + A4 인쇄 스타일
js/myp-data.js    과목군별 Criterion, 수준 구간, 등급 경계·설명
js/demo-data.js   완성본 예시용 가상 데이터 (3학년 11과목, 2개 반)
js/app.js         템플릿·나이스 파일 읽기, 변환 계산, 4단계 화면, 파일 저장/불러오기
```

## 기능

1. **기준 템플릿**: 빈 양식(xlsx) 내려받기, 업로드 시 오류 검사(형식, 구간 겹침·빈틈), 수준 범위 처리(높은 쪽/낮은 쪽), 등급 경계 수정
   - `과목` 시트: 학년, 나이스 과목명, MYP 과목군, 성적표 표시명, 근거 합치는 방식(평균·최근·최고)
   - `규칙` 시트: 학년, 나이스 과목명, 나이스 영역명, Criterion, 배점(`10` 또는 `18~20`), 수준(`8` 또는 `7~8`)
2. **나이스 성적 파일**: 수행평가 강의실별 일람표(XLS data) 여러 개 업로드, 템플릿 영역·만점 대조
   - 한 영역을 여러 기준으로 채점한 경우 합계를 기준별 점수 차가 가장 작은 조합으로 나누고 "추정"으로 표시
3. **검토 · 수정**: 반별 전 과목 등급 요약, 과목별 영역 점수·기준별 수준(제안값), 수준 직접 수정, 과목별 의견 작성, 확인 필요 항목 표시

계산 방식은 IB *MYP: From principles into practice*의 평가·보고 규정을 따릅니다. 기준을 모두 평가하지 않은 과목은 등급 없이 수준만 보고하고, 학기 수준은 교사 판단을 돕는 제안값으로 계산합니다. 자세한 내용은 PRD 7장에 있습니다.
   - **추가 기록 (선택)**: ATL 기능 발달 단계, 학습자상, 공동체 프로젝트(3학년) 입력 — 일괄 입력·엑셀 붙여넣기 지원
4. **성적표 출력**: 학생 1명당 전 과목 성적표(MYP 연차·담당 교사·과목별 의견·등급 설명·ATL·학습자상·공동체 프로젝트·Criterion 이름·등급 경계표·종합 의견·서명란 선택), 인쇄/PDF 저장, 결과 CSV 내보내기
   - 2쪽 이상이면 학생마다 새 쪽에서 시작하고, 쪽마다 위쪽에 학생 이름·학년·반·번호·학번을 반복 인쇄, 마지막에 "성적표 끝" 표시

**완성본 예시**: 상단 버튼 또는 주소 끝에 `#demo`를 붙여 열면(예: `https://jstd-jeostdu.github.io/ib-myp-report/#demo`) 가상의 3학년 2개 반·11과목 데이터가 채워진 상태로 시작합니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 을 엽니다.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다.

JS·CSS를 고친 뒤 배포할 때는 `index.html`의 `?v=2.0.0` 숫자를 올려야 교사들의 브라우저가 이전 파일을 캐시에서 쓰지 않습니다.

> 저장소가 공개(public)여도 코드만 공개되며, 학생 데이터는 저장소나 서버에 올라가지 않습니다. 나이스 파일과 저장한 JSON·CSV 파일에는 학생 이름과 성적이 들어 있으니 저장소 폴더에 넣지 마세요.
